# Unyx Bridge

Android Auto через CarLife для VW ID.Unyx. Український інтерфейс, власний підпис APK та діагностика.

## Завантаження і вихідний код

[Перевірені збірки та повний вихідний код](https://github.com/Nickolya77777/unyx-bridge/releases).

Для кожної версії у релізі є APK і повний архів `Unyx-Bridge-<version>-source.zip`.
Саме цей архів містить Android-проєкт, тести, build.ps1, інструкцію docs/UNYX_BUILD.md та вихідні файли.
Приватні ключі підпису, signing.properties і журнали користувача до публікації не входять.

## Оновлення

У 0.7 повернуто оновлювач із власного HTTPS update.json у цьому репозиторії.
APK має відповідати пакету ua.local.unyxbridge, вищій версії, розміру, SHA-256 та сертифікату збірок Unyx Bridge.
Остаточну перевірку підпису виконує установник Android. Оновлення встановлює користувач після зупинки моста.
Першу 0.7 потрібно встановити вручну поверх попередньої версії.

## Логи

ZIP у Google Drive передає звіт у встановлений застосунок Drive. Обліковий запис і папку обирає користувач.
Статус передавання не є підтвердженням завершення завантаження на сервер. Логи не публікуються в цьому репозиторії.

## Перевірка

0.7.0-unyx: 651 JVM-тест без помилок; Android Lint без помилок (59 попереджень).
Перевірено release-підпис APK. Перевірка 0.7 у телефоні та автомобілі ще потрібна.
Просторова AR-навігація через CarLife не підтверджена.
